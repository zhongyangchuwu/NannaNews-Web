# 公开 PDF 输入

此目录仅用于已经决定公开的南哪消息 PDF；上传前确认有权公开分发原件及提取全文。分支和 PR 中的原件也已公开，不是合并后才公开。

有仓库写权限的人可通过 GitHub **Add file → Upload files** 上传新增 PDF，选择新建分支并建立非草稿 PR。Actions 在同一 PR 写回分析后的主数据，审阅、合并主分支后才更新网页。只上传 PDF，不混入代码或手改目录；机器人写回目录后，下一批请另开 PR。详见[网页上传说明](../README.md#github-网页上传与审阅发布)。

近期开发用 PDF 先留在仓库外，使用：

```sh
npm run import:pdf -- /path/to/local/pdf-directory
```

不要为了本地开发将原件复制到本目录，也不要提交解析证据、数据库或凭据。本地私有主数据和生成的网页文件不能整体迁入公开仓库。
